# POLYGON RUSH

Course de moto arcade low-poly sur l'itinéraire réel Catane → Falcone, avec progression roguelite.

**Jouer : https://elzuzu.github.io/polygon-rush-play/v3/**

Commandes : ↑/Z accélérer · ↓/S freiner · ←→/QD tourner · Espace boost · Maj dérapage · E objet · Échap menu · M son.

Ce dépôt ne contient que la version compilée du jeu.
